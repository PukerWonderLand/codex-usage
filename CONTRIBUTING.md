# Contributing

Thanks for helping improve Codex Usage.

1. Use Node.js 22.13 or newer.
2. Create a focused branch from `main`.
3. Keep all usage processing local and never add prompts, responses, credentials, or real session logs to fixtures.
4. Add or update tests for behavior changes.
5. Run `npm run ci` before opening a pull request.

Commit messages should be concise and explain the user-visible change. Pull requests should describe the change, its privacy impact, and how it was tested.
